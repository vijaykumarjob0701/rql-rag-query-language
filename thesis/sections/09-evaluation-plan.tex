\section{Evaluation: what we measured vs what remains}
\label{sec:eval}

\noindent\textit{This section separates \textbf{feasibility evidence already on disk} from \textbf{citation-grade ANN/RAG work that is not claimed}.
No fabricated metrics.}

\subsection{What we measured (feasibility / plumbing)}
\label{sec:eval-measured}
\begin{itemize}[leftmargin=*]
  \item \textbf{Deterministic unit tests (not IR benchmarks):}
    RRF on fixed lists (\texttt{experiments/harness/test\_rrf\_fusion.py} $\rightarrow$ \texttt{experiments/results/rrf\_unit\_test.txt});
    weighted linear/CC on fixed toy scores (\texttt{test\_linear\_fusion.py} $\rightarrow$ \texttt{experiments/results/linear\_fusion/});
    MaxSim toy check (\texttt{test\_maxsim\_late.py});
    filter-strategy chooser (\texttt{test\_filter\_strategy\_chooser.py}).
  \item \textbf{Schema + compile stack:}
    LogicalPlan/PhysicalPlan JSON Schema \texttt{0.1.0-draft} validated by \texttt{validate\_plans.py};
    toy parser 4/4 (journal 0022);
    planner stub 4 logical $\times$ 3 profiles $= 12/12$ (journal 0023);
    adapter emit smoke hybrid-RRF + filtered-dense $\times$ 3 $= 6/6$ sketches (journal 0024);
    offline E2E CLI 4 queries $\times$ 3 profiles $= \mathbf{12/12}$ schema-validated (\texttt{experiments/results/e2e/run\_validate.txt}; journal 0026).
  \item \textbf{Colab synthetic FANNS PRE/POST smoke} (journal 0029--0030):
    T4 GPU, \texttt{faiss-gpu}~1.15.1; $N{=}50{,}000$, $d{=}128$, seed~$42$; selectivities $\{0.01,0.05,0.1,0.5\}$;
    artifacts under \texttt{experiments/results/fanns/colab\_synth\_20260916\_233628/}.
    \textbf{Honest label:} plumbing + qualitative PRE vs POST latency/QPS \emph{shape} on synthetic data only.
    \textbf{Not} P0; \textbf{not} SIFT1M; Recall@$10{=}1.0$ on this easy setup is \textbf{not} a citation-ready ANN quality claim.
  \item \textbf{SIFT1M FAISS HNSW32 filtered-ANN microbench} (journal 0038):
    \texttt{faiss-cpu}~1.15.1; full base $N{=}10^6$, $d{=}128$, $n_q{=}1000$, $k{=}10$, seed~$42$;
    index \texttt{HNSW32} ($M{=}32$, \texttt{efConstruction}{=}200, \texttt{efSearch}{=}64);
    PRE via \texttt{IDSelectorBitmap}; POST top-($k{\times}50$) then filter;
    filtered GT = \texttt{IndexFlatL2}+\texttt{IDSelectorBitmap};
    artifacts \texttt{experiments/results/fanns/sift1m\_faiss\_HNSW32\_20260917\_022017/}.
    Example (real): at $s{=}0.1$, PRE recall@$10{\approx}0.90$ / ${\sim}0.24$\,ms p50; POST ${\approx}0.998$ / ${\sim}1.5$\,ms p50.
    \textbf{Honest label:} stronger than NumPy brute; synthetic Bernoulli predicates; single depth setting;
    \textbf{not} ACORN (or any paper) numbers; live adapters and RAG judgments still absent.
\end{itemize}
Planned-run printer \texttt{print\_planned\_runs.py} emits \texttt{score=NOT\_RUN} only---by design.
