\section{Physical planning (original sketch)}
\label{sec:optimizer}

\noindent\textit{This section is \hypothesis{} unless a citation marks established prior art.}

\subsection{Physical filter modes}
Grounded in FANNS practice and multimodal re-reads of ACORN~\citep{patel2024acorn}, Filtered-DiskANN~\citep{gollapudi2023filtered}, and VBASE~\citep{zhang2023vbase}:
\[
\mathrm{FilterExec}\in\{\mathrm{PRE},\,\mathrm{POST},\,\mathrm{ITERATIVE},\,\mathrm{SUBGRAPH},\,\mathrm{SPECIALIZED},\,\mathrm{AUTO}\}.
\]
\begin{itemize}
  \item $\mathrm{PRE}$: restrict candidates then exact/ANN on survivors (high selectivity / small survivor set).
  \item $\mathrm{POST}$: ANN then predicate; often needs over-fetch; brittle under low selectivity or low query--predicate correlation~\citep{patel2024acorn}.
  \item $\mathrm{SUBGRAPH}$: ACORN-like predicate-subgraph traversal when the backend capability exists~\citep{patel2024acorn}.
  \item $\mathrm{SPECIALIZED}$: label/equality-constrained graph indices (FilteredVamana / StitchedVamana class) when the predicate matches advertised capabilities~\citep{gollapudi2023filtered}.
  \item $\mathrm{ITERATIVE}$: Volcano-style $\mathrm{Open}/\mathrm{Next}/\mathrm{Close}$ ANN with early-stop (relaxed monotonicity class) enabling filter-during-traversal and join patterns~\citep{zhang2023vbase}.
  \item $\mathrm{AUTO}$: choose using stats (selectivity, specificity, correlation, empty-result risk); \textbf{never} violate ACL hard constraints.
\end{itemize}

\paragraph{Capability negotiation.}
Adapters must advertise which modes exist.
Missing $\mathrm{SUBGRAPH}$/$\mathrm{SPECIALIZED}$/$\mathrm{ITERATIVE}$ forces fallback --- the algebra must not pretend universal support \hypothesis{}.

\subsection{Cost vector}
Unlike classical selectivity-only costing, plans expose a vector:
\begin{enumerate}
  \item Recall proxy (candidate depth, filter empty-result risk, low-specificity risk~\citep{gollapudi2023filtered}),
  \item Latency (p50/p95 targets),
  \item ACL safety (boolean hard constraint),
  \item Token/dollar budget (embeddings, rerankers, rewrites).
\end{enumerate}
BlinkDB-style explicit budgets~\citep{agarwal2013blinkdb} motivate surface options such as \texttt{RECALL TARGET} / \texttt{LATENCY} \hypothesis{}.

\subsection{Fusion and rewrite rules}
Examples \hypothesis{}:
\begin{itemize}
  \item Independent channel searches $\rightarrow$ parallel schedule; fuse with \(\mathrm{Fuse}_{rrf}\) when scores incomparable~\citep{cormack2009rrf}, else \(\mathrm{Fuse}_{linear}\) / \(\mathrm{Fuse}_{ltr}\) when calibrated~\citep{bruch2023fusion} \hypothesis{} (policy).
  \item \(\mathrm{Search}_{late}\) compile ladder: native MaxSim multi-vector~\citep{khattab2020colbert} \established{} scoring;
    else PLAID-class centroid interaction + multi-stage prune~\citep{santhanam2022plaid} \established{} as mechanism (journal 0014) if \texttt{late\_plaid} advertised;
    else MUVERA FDE$\rightarrow$MIPS~$+$~$\mathrm{MAXSIM\_RERANK}$~\citep{jayaram2024muvera} if \texttt{fde\_mips} capability exists (journal 0013);
    else fail closed with EXPLAIN (do not silently substitute single-vector cosine).
  \item Low selectivity + $\mathrm{POST}$ $\rightarrow$ rewrite toward $\mathrm{ITERATIVE}$/$\mathrm{SUBGRAPH}$/$\mathrm{SPECIALIZED}$/over-fetch depending on capabilities and predicate shape.
  \item $\mathrm{VSimJoin}$ $\rightarrow$ prefer iterator nested loops when $\mathrm{ITERATIVE}$ exists~\citep{zhang2023vbase}.
\end{itemize}
