\section{Applications to RAG patterns}
\label{sec:apps}

Patterns below map to example programs in the companion repo (\texttt{examples/*.rql}).

\begin{itemize}
  \item Dense + ACL metadata filter (reliability-first pushdown).
  \item \textbf{Hybrid BM25+dense with RRF / linear:}
    \(\mathrm{Fuse}_{rrf}(k{=}60)\) over channel-local rankings~\citep{cormack2009rrf} \established{} as the portable default when scores are incomparable;
    optional cross-encoder \(\mathrm{Rerank}\) afterward (\texttt{examples/02-hybrid-rrf.rql}).
    Prefer \(\mathrm{Fuse}_{linear}(\alpha)\) (Bruch-style normalised convex combination~\citep{bruch2023fusion} \established{} as mechanism, journal 0016) when calibrated scores + small labels exist;
    keep RRF under zero-shot / uncalibrated scores~\citep{chen2022ood} \established{} as the competing literature recommendation (journal 0017; preference rule \hypothesis{}, \S\ref{sec:fuse-preference});
    optional \(\mathrm{Fuse}_{condorcet}\) (pairwise-majority sort)~\citep{montague2002condorcet} \established{} as mechanism (journal 0018) for majoritarian A/B without replacing RRF;
    escalate to \(\mathrm{Fuse}_{ltr}\) for multi-feature learned fuse \hypothesis{}
    (\texttt{examples/03-hybrid-linear-weights.rql}, \texttt{12-fuse-learned-explain.rql}).
  \item Multi-query / HyDE-style rewrite as plan nodes (costed) \provisional{}.
  \item Parent expansion and bounded multi-hop graph retrieval \provisional{}.
  \item \textbf{Late-interaction search:}
    logical \(\mathrm{Search}_{late}\) with MaxSim-sum semantics~\citep{khattab2020colbert} \established{};
    optional planner rewrite toward PLAID-class centroid interaction/pruning~\citep{santhanam2022plaid} \established{} as mechanism (journal 0014) or MUVERA FDE$\rightarrow$MIPS$+$MaxSim rerank~\citep{jayaram2024muvera} when the adapter lacks native multi-vector support \hypothesis{}
    (\texttt{examples/09-colbert-late-interaction.rql}).
\end{itemize}

RQL's value is making these patterns \emph{comparable} under EXPLAIN and shared eval harnesses \hypothesis{} --- not inventing RRF or MaxSim themselves \established{}.
