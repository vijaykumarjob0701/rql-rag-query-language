\section{Applications to RAG patterns}
\label{sec:apps}

Patterns below map to example programs in the companion repo (\texttt{examples/*.rql}).

\begin{itemize}
  \item Dense + ACL metadata filter (reliability-first pushdown).
  \item \textbf{Hybrid BM25+dense with RRF:}
    \(\mathrm{Fuse}_{rrf}(k{=}60)\) over channel-local rankings~\citep{cormack2009rrf} \established{} as the portable default when scores are incomparable;
    optional cross-encoder \(\mathrm{Rerank}\) afterward (\texttt{examples/02-hybrid-rrf.rql}).
    Prefer \(\mathrm{Fuse}_{linear}\) / learned mix when calibrated scores exist \hypothesis{} (\texttt{examples/03-hybrid-linear-weights.rql}, \texttt{12-fuse-learned-explain.rql}).
  \item Multi-query / HyDE-style rewrite as plan nodes (costed) \provisional{}.
  \item Parent expansion and bounded multi-hop graph retrieval \provisional{}.
  \item Late-interaction search with optional planner rewrite \provisional{}.
\end{itemize}

RQL's value is making these patterns \emph{comparable} under EXPLAIN and shared eval harnesses \hypothesis{} --- not inventing RRF itself \established{}.
